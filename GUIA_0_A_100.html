1¿Por qué Electron?

Electron permite construir aplicaciones de escritorio usando tecnologías web (HTML, CSS, JS). Combina Chromium (el motor de Chrome) con Node.js, dando acceso al sistema de archivos, notificaciones nativas y hardware del PC.

⚡

Ventajas

Un solo codebase para Windows, macOS y Linux. Reusar todo el conocimiento web. Ecosistema npm gigante disponible.

⚖️

Alternativas

Tauri (Rust, más ligero). NW.js (más viejo). Flutter (Dart). Electron gana en madurez y ecosistema.

2Arquitectura de una App Profesional

Una app de escritorio profesional no es solo "funciona". Debe cumplir:

contextIsolation, sin nodeIntegration en renderer, CSP.

Experiencia Nativa

📦

Packaging

Instalador .exe con icono, firma de código, uninstaller.

🔄

Auto-Update

electron-updater + GitHub Releases. El software evoluciona solo.

📁

MNE Structure

Componentes <300 líneas. UI separada de lógica. Sin monolitos.

5Main Process vs Renderer Process

Esta es la dualidad fundamental de Electron. Confundirla es el error #1 de los principiantes.

🔵 Main Process (electron/main.js)

Corre en Node.js. Tiene acceso al sistema de archivos, la base de datos, el sistema operativo. Es el backend.

// Solo en main.js
const fs = require('fs')
const db = new SQL.Database()

🟢 Renderer Process (React)

Corre en Chromium (como un browser). NO tiene acceso directo a Node.js. Es el frontend.

// En React — via preload bridge
const result = await window.equilibrium
  .activities.getAll()
La regla de oro: El Renderer NUNCA toca la DB ni el FS directamente. Todo pasa por IPC → preload → main.

6Base de Datos Local con sql.js

sql.js es SQLite compilado a WebAssembly. No requiere compiladores de C++ (a diferencia de better-sqlite3), lo que lo hace perfecto para desarrollo inmediato en Windows.

const initSqlJs = require('sql.js')
const SQL = await initSqlJs()

// Cargar DB existente del disco
const buffer = fs.readFileSync(dbPath)
const db = new SQL.Database(buffer)

// Crear nueva
const db = new SQL.Database()

// Guardar al disco después de cada escritura
function persist() {
  const data = db.export()
  fs.writeFileSync(dbPath, Buffer.from(data))
}

// Ejecutar consultas
db.run('INSERT INTO activities (...) VALUES (?)', [value])
const res = db.exec('SELECT * FROM activities')

// Convertir resultado a array de objetos
const { columns, values } = res[0]
const rows = values.map(row => {
  const obj = {}
  columns.forEach((col, i) => obj[col] = row[i])
  return obj
})

📍 ¿Dónde guardar la DB?

Siempre en app.getPath('userData') — nunca en el directorio de instalación. En Windows: C:\Users\[usuario]\AppData\Roaming\equilibrium\

7El Sistema IPC — La Columna Vertebral

IPC (Inter-Process Communication) es cómo el frontend (React) habla con el backend (Electron).

1. Define el canal en main.js

ipcMain.handle('activities:getAll', () => {
  return rowsToObjects(db.exec('SELECT ...'))
})

2. Expón via preload.js

contextBridge.exposeInMainWorld(
  'equilibrium', {
    activities: {
      getAll: () => ipcRenderer
        .invoke('activities:getAll')
    }
  }
)

3. Llama desde React

const data = await window.equilibrium.activities.getAll()
setActivities(data)

8UI/UX de Productividad

🪟

Ventana Frameless

Elimina la barra del sistema. Crea titlebar propio con -webkit-app-region:drag.

🌑

Dark Mode Forzado

nativeTheme.themeSource='dark' desde el main process. Nunca depender del sistema.

✨

Glassmorphism

backdrop-filter:blur(20px) con fondos semi-transparentes. Efecto premium inmediato.

📊

Visualización

Un Radar Chart muestra balance de forma intuitiva. Los números solos no comunican.

⚡

FAB

Floating Action Button siempre visible. Reduce fricción del flujo principal a 1 clic.

🧠

Insights Automáticos

La app piensa por el usuario. Si lleva X días sin actividad, le avisa. Retención = valor.

9Build y Packaging

# Build del frontend (Vite)
pnpm build

# Packaging con electron-builder
pnpm electron:build

# Output: dist-electron/
# ├── Equilibrium Setup 1.0.0.exe  ← Instalador NSIS
# └── win-unpacked/                ← Portable

electron-builder config (en package.json)

"build": {
  "appId": "com.nelxson2099.equilibrium",
  "productName": "Equilibrium",
  "win": { "target": "nsis", "icon": "assets/icon.ico" },
  "nsis": { "oneClick": false, "allowToChangeInstallationDirectory": true }
}
Para producción: Convierte icon.png a icon.ico (256x256) con convertio.co y úsalo en la configuración de electron-builder.
